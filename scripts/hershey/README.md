# Hershey fonts

`scripts.jhf` (Script Simplex, a single-stroke cursive) and `futural.jhf`
(Futura Light, a single-stroke print hand) are Dr. A. V. Hershey's vector
fonts, created at the U.S. National Bureau of Standards in 1967 and
distributed with the note: "Use of the Hershey fonts is unrestricted, as
long as you include this notice." They were taken from the MIT-licensed
Hershey-Fonts Python package (https://github.com/apshu/HersheyFonts).

Toby writes with them in Work Mode because each letter is a path a pen can
follow, which an ordinary outline font is not.
